# Mellon — logo

Tres hojas forman una **M**. Cada hoja lleva un pilar en sus nervaduras:

| Hoja | Pilar | Nervaduras |
|---|---|---|
| Izquierda | **Terreno** | curvas de nivel |
| Centro | **Alianza** | nervadura orgánica que se ramifica |
| Derecha | **Rigor** | nervaduras rectas y paralelas |

## Colores

| Uso | Valor |
|---|---|
| Verde bosque | `#1F4D3A` |
| Dorado | `#C9A24B` |
| Tinta negra | `#111111` |

## Archivos

| Archivo | Cuándo usarlo |
|---|---|
| `svg/mellon-logo.svg` | Logo principal a color (≥ 64 px de alto) |
| `svg/mellon-logo-simple.svg` | Versión con trazos gruesos para tamaños pequeños (< 64 px) |
| `svg/mellon-logo-black.svg`, `-green.svg` | Una sola tinta sobre fondo claro |
| `svg/mellon-logo-white.svg` | Una sola tinta sobre fondo oscuro o verde |
| `svg/mellon-logo-simple-black.svg`, `-simple-white.svg` | Una tinta, versión simplificada |
| `favicon.ico`, `png/favicon-*.png` | Favicon (16/32/48) |
| `png/apple-touch-icon.png`, `png/icon-192.png`, `png/icon-512.png` | Íconos de app (mosaico verde con marca blanca) |
| `png/mellon-logo-*.png` | Exportaciones con fondo transparente |
| `source/gen.py` | Generador de los SVG (`python3 source/gen.py <carpeta>`) |

## Reglas de uso

- Margen libre mínimo alrededor: el ancho de la hoja central.
- Por debajo de 64 px de alto, usar siempre la versión `simple`.
- No recolorear las hojas por separado ni cambiar el orden (Terreno · Alianza · Rigor).
- En una sola tinta las nervaduras son recortes: el fondo se ve a través de ellas.

## Nota de marca

*Mellon* y la puerta de Moria vienen del universo de Tolkien. El nombre y la idea
son inspiración; este logo es un diseño propio. Evitar copiar el broche de la
Comunidad, la escritura élfica o el diseño de la puerta de las películas.
